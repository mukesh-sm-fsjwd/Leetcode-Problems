This is where I track my problem solving practice — DSA questions, pattern based practice, and the daily challenge. ## Daily challenge streak

LeetCode has a daily problem, and I try to solve it every day to keep the streak going (the flame icon next to the profile shows this). Solutions for these go into `practice/daily-challenge/`, usually named by date so it is easy to find a specific day later.

This is less about difficulty and more about consistency — some days the daily problem is easy, some days it is not, but the point is showing up every day.

---

## How I approach a problem

1. Read the problem twice before touching code, and try to restate it in my own words
2. Think about brute force first, even if I already suspect a better approach
3. Work out the pattern (two pointers, sliding window, DP, etc.) before writing code
4. Code it, test with the given examples, then think about edge cases
5. If I got stuck or looked up a hint, I note that down instead of pretending I solved it cold
